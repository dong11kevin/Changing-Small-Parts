Morphogenesis via Formal Grammar

An L-System Analysis of the Chimera Sandbox

An L-System (Lindenmayer System) is a formal grammar introduced in 1968 by biologist Aristid Lindenmayer to model plant growth. It consists of an alphabet of symbols, an initial string called an axiom, and production rules that translate symbols into geometric structures.

This application operates as an L-System. The input string of A, T, C, and G characters serves as the axiom, while the translation logic acts as the production grammar. Instead of moving a graphic turtle forward, the grammar maps three-character sequences directly to geometric properties: sequences starting with GA shift color hue toward red, TT or CT expand the radius, and each valid block in the third sequence adds a radial node.

The system differs from Lindenmayer's original model in how it handles time. Traditional L-systems are recursive, repeatedly feeding output strings back into production rules to build fractal patterns across multiple iterations. This application uses a single-pass parser that stops upon encountering terminal stop codons (such as TAG). It replaces recursive growth with a direct mapping from sequence to visual form.

Reference:
Lindenmayer, A. (1968). "Mathematical models for cellular interactions in development I. Filaments with one-sided inputs." Journal of Theoretical Biology, 18(3), 280-299.

⚗️ Production Grammar Controls

Geometric Interpretation Rules

  • System Constraint: The parser evaluates 3-character blocks of A, T, C, G. Stop codons (TAG, TAA, TGA) terminate parsing for that input.
  • Axiom I (Color Hue): Blocks starting with GA shift hue toward red. Blocks starting with AA or CG shift hue toward blue/purple.
  • Axiom II (Radial Scale): Blocks starting with TT or CT increase the body radius. Short sequences keep the scale minimal.
  • Axiom III (Topology): Each parsed 3-character block generates one radial appendage.
